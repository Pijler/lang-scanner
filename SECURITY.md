# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue. Report it privately through [GitHub Security Advisories](https://github.com/Pijler/lang-scanner/security/advisories/new).

You will get an answer within a few days. Fixes are released as a new patch version and announced in the advisory.

## Supported versions

Only the latest released version of `pijler/lang-scanner` receives security fixes.

## Official packages

The only official packages are published on Packagist under the [`pijler`](https://packagist.org/packages/pijler/) vendor, from the [Pijler](https://github.com/Pijler) GitHub organization. Packages with similar names under other vendors are **not** ours.
